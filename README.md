# 🌌 Cosmic Odyssey — 3D Solar System & Milky Way Explorer

**Explore the universe through an interactive 3D experience.** 🚀

## 🔍 The Problem

Understanding the Solar System and the Milky Way can be challenging when learning resources rely mainly on static images, diagrams, or text. These methods often make it difficult to visualize celestial objects, explore their relationships, and imagine the scale of space.

## 💡 The Solution

**Cosmic Odyssey** is an interactive 3D space exploration web application that brings the universe to life through immersive visualizations. Users can explore the Solar System, switch to a Milky Way view, search for planets and moons, discover celestial information, and interact with simulation controls—all through a single web interface.

## 🎯 Why Is This Project Needed?

The project aims to make space exploration more engaging, accessible, and easier to understand. By combining 3D graphics with interactive web technologies, it provides a more hands-on learning experience for students, astronomy enthusiasts, and curious explorers.

It also demonstrates how modern web development can be used to create educational and visually interactive applications.

## ✨ Key Features

- 🌍 **3D Solar System:** Explore the Sun, planets, and selected celestial bodies.
- 🌌 **Milky Way View:** Experience an interactive visualization of our galaxy.
- 🔭 **Planet & Moon Search:** Find celestial objects by name.
- 🪐 **Celestial Information:** Discover details about selected objects.
- 🎮 **Simulation Controls:** Adjust speed, pause motion, toggle orbits and labels, and reset the view.
- 🔊 **Voice Narration:** Listen to supported celestial information.
- 🛰️ **Mission Interface:** Explore the concept of space travel through an interactive mission experience.
- 📱 **Responsive Design:** Use the application across desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

| Technology | Purpose |
